⚡ Optimize regex evaluation for dynamic patterns in validate_set_variables

💡 **What:** Replaced the list of individual compiled regex objects with a single combined regex using `|` alternation and non-capturing groups.
🎯 **Why:** The previous logic iterated over all compiled dynamic patterns using `any()` for each unreferenced variable, which is inefficient.
📊 **Measured Improvement:** In a benchmark with 100 dynamic patterns and ~7,800 unreferenced variables, the evaluation time dropped from ~0.21s to ~0.013s, a 16x speedup.
